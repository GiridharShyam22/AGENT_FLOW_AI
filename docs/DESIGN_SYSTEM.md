# AgentFlow AI Design System

Version: 1.0

---

# Design Philosophy

AgentFlow AI is an enterprise AI customer support platform.

The interface should feel:

- Professional
- Modern
- Minimal
- Fast
- Calm
- Intelligent
- Premium

Inspired by:

- Linear
- OpenAI ChatGPT Team
- Vercel
- Notion AI
- Atlassian Intelligence

Never flashy.
Never cluttered.
Everything has purpose.

✓ Have hover animations

✓ Support dark mode

✓ Be reusable

✓ Avoid inline styling

✓ Keep logic separate from UI
